Visitez le [site officiel](https://xmcl.app) pour télécharger l'application !

Si vous avez winget, vous pouvez l'installer via la commande :

```bash
winget install CI010.XMinecraftLauncher
```

Installation via Homebrew (macOS tap) :

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

Sur Linux, XMCL est également disponible sur Flathub :

```bash
flatpak install flathub app.xmcl.voxelum
```

## Fonctionnalités

- 📥 **Téléchargement et complétion automatique**. Téléchargement de `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` depuis les miroirs officiels ou tiers.
- ⚡️ **Téléchargement ultra-rapide**. Réutilisation des sockets via agents HTTP/HTTPS et téléchargement parallèle de fichiers fragmentés.
- 💻 **Multiplateforme**. Basé sur Electron, supportant 🗔 Windows 10/11, 🍎 macOS et 🐧 Linux.
- 📚 **Gestion multi-instances**. Créez des instances isolées pour séparer les versions, mods et options de lancement.
- 🗂 **Gestion intelligente des ressources**. Liens durs et symboliques pour installer les ressources sans duplication de fichiers et économiser l'espace disque ! 😆
- 🔥 **Support natif CurseForge & Modrinth**. Téléchargez mods et ressources directement dans le lanceur.
- 📦 **Importation/Exportation de modpacks**. Compatibilité totale avec les formats de modpacks CurseForge et Modrinth !
- 🔒 **Système multi-comptes**. Authentification Microsoft, Mojang Yggdrasil API, [ely.by](https://ely.by/) et serveurs d'authentification personnalisés !
- 🔗 **Connexion multijoueur P2P**. Jouez en réseau local virtuel sur Internet avec vos amis sans configuration réseau complexe !
- 🔑 **Signature de code & paquets modernes**. Sur Windows, prise en charge de `appx` et `appinstaller` sans avertissement SmartScreen ! 😎
