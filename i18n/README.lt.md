Apsilankykite [oficialioje svetainėje](https://xmcl.app) ir atsisiųskite programą!

Jei turite įdiegtą winget:

```bash
winget install CI010.XMinecraftLauncher
```

Diegimas per Homebrew (macOS tap):

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

Linux sistemoje XMCL taip pat pasiekiamas Flathub:

```bash
flatpak install flathub app.xmcl.voxelum
```

## Funkcijos

- 📥 **Automatinis atsisiuntimas ir papildymas**. `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` atsisiuntimo palaikymas.
- ⚡️ **Ypatingai greitas atsisiuntimas**. Ryšių pakartotinis naudojimas ir lygiagretus failų dalių atsisiuntimas.
- 💻 **Kelių platformų palaikymas**. Sukurtas su Electron: 🗔 Windows 10/11, 🍎 macOS ir 🐧 Linux.
- 📚 **Kelių profilių valdymas**. Kurkite atskirus profilius žaidimo versijoms, modifikacijoms ir paleidimo nustatymams.
- 🗂 **Efektyvus išteklių valdymas**. Naudoja kietąsias ir simbolines nuorodas, kad sutaupytų vietos diske be failų dubliavimo! 😆
- 🔥 **Integruotas CurseForge & Modrinth**. Naršykite ir atsisiųskite modifikacijas tiesiogiai programoje.
- 📦 **Modifikacijų rinkinių importas ir eksportas**. Visiškas suderinamumas su CurseForge ir Modrinth standartais!
- 🔒 **Kelių paskyrų palaikymas**. Microsoft prisijungimas, Mojang Yggdrasil API, [ely.by](https://ely.by/) ir kiti serveriai!
- 🔗 **P2P kelių žaidėjų režimas**. Žaiskite su draugais virtualiame LAN tinkle internetu be sudėtingų nustatymų!
- 🔑 **Kodo pasirašymas ir šiuolaikiniai paketai**. Windows sistemoje palaikomi `appx` ir `appinstaller` be SmartScreen įspėjimų! 😎
