Navštivte [oficiální stránku](https://xmcl.app) ke stažení aplikace!

Pokud máte nainstalovaný winget, můžete jej použít k instalaci:

```bash
winget install CI010.XMinecraftLauncher
```

Instalace přes Homebrew (macOS tap):

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

Na Linuxu je XMCL k dispozici také na Flathubu:

```bash
flatpak install flathub app.xmcl.voxelum
```

## Funkce

- 📥 **Stahování a automatické dokončení**. Podpora stahování `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` z oficiálních i komunitních zrcadel.
- ⚡️ **Vysokorychlostní stahování**. Znovupoužití soketů přes HTTP/HTTPS agenty a paralelní stahování částí souborů.
- 💻 **Multiplatformní**. Postaveno na Electronu s plnou podporou pro 🗔 Windows 10/11, 🍎 macOS a 🐧 Linux.
- 📚 **Správa více instancí**. Vytvářejte izolované profily pro oddělení verzí, modifikací a spouštěcích parametrů.
- 🗂 **Efektivní správa zdrojů**. Využití pevných a symbolických odkazů pro instalaci modů bez duplikace souborů a plýtvání místem na disku! 😆
- 🔥 **Integrovaná podpora CurseForge & Modrinth**. Hledejte a stahujte mody i balíčky zdrojů přímo v launcheru.
- 📦 **Import a export modpacků**. Plná kompatibilita se standardními formáty CurseForge a Modrinth!
- 🔒 **Podpora více uživatelských účtů**. Oficiální přihlášení Microsoft, Mojang Yggdrasil API, [ely.by](https://ely.by/) a vlastní autentizační servery!
- 🔗 **P2P multiplayer**. Hrajte s přáteli přes virtuální LAN přes internet bez složitého nastavování sítě!
- 🔑 **Digitální podpis a moderní balíčky**. Ve Windows jsou podporovány balíčky `appx` a `appinstaller` bez hlášení SmartScreen! 😎
