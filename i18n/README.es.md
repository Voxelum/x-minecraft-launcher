¡Visita el [sitio oficial](https://xmcl.app) para descargar la aplicación!

Si tienes winget instalado, puedes usarlo para instalar:

```bash
winget install CI010.XMinecraftLauncher
```

Instalación mediante Homebrew (macOS tap):

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

En Linux, XMCL también está disponible en Flathub:

```bash
flatpak install flathub app.xmcl.voxelum
```

## Características

- 📥 **Descarga y autocompletado**. Admite la descarga de `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` desde espejos oficiales o de terceros.
- ⚡️ **Descarga rápida**. Reutiliza sockets mediante agentes HTTP/HTTPS y descarga archivos por partes de forma concurrente.
- 💻 **Multiplataforma**. El lanzador está basado en Electron y es compatible con 🗔 Windows 10/11, 🍎 macOS y 🐧 Linux.
- 📚 **Multi-instancia**. Los usuarios pueden crear múltiples instancias para aislar versiones, mods y configuraciones de inicio.
- 🗂 **Gestión eficiente de recursos**. Utiliza enlaces duros y simbólicos para instalar recursos sin duplicar archivos y ahorrando espacio en disco. 😆
- 🔥 **Soporte integrado de CurseForge y Modrinth**. Descarga recursos directamente dentro del lanzador.
- 📦 **Importación y exportación de modpacks**. ¡Total compatibilidad con modpacks de CurseForge y Modrinth!
- 🔒 **Múltiples sistemas de cuentas**. Inicio de sesión con Microsoft, Mojang Yggdrasil API, [ely.by](https://ely.by/) y servidores de autenticación de terceros.
- 🔗 **Conexión P2P entre usuarios**. ¡Juega en multijugador por LAN virtual a través de Internet sin configuraciones complejas!
- 🔑 **Firma de código y empaquetado moderno**. En Windows, se admiten `appx` y `appinstaller` sin alertas de SmartScreen. 😎
