قم بزيارة [الموقع الرسمي](https://xmcl.app) لتحميل التطبيق!

إذا كان لديك winget مثبتًا:

```bash
winget install CI010.XMinecraftLauncher
```

التثبيت عبر Homebrew (macOS tap):

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

على Linux، يتوفر XMCL أيضًا على Flathub:

```bash
flatpak install flathub app.xmcl.voxelum
```

## المميزات

- 📥 **تنزيل وإكمال تلقائي**. دعم تنزيل `Minecraft` و `Forge` و `Fabric` و `Quilt` و `OptiFine` و `JVM` من المصادر الرسمية والخوادم البديلة.
- ⚡️ **تنزيل فائق السرعة**. إعادة استخدام الاتصالات عبر وكلاء HTTP/HTTPS وتنزيل الملفات المقسمة بالتوازي.
- 💻 **متعدد المنصات**. مبني على Electron ويدعم 🗔 Windows 10/11 و 🍎 macOS و 🐧 Linux.
- 📚 **إدارة الحسابات والمثيلات**. إنشاء ملفات تعريف معزولة لفصل إصدارات اللعبة والتعديلات وإعدادات التشغيل.
- 🗂 **إدارة ذكية للموارد**. استخدام الروابط الصلبة والرمزية لتوفير مساحة القرص دون تكرار الملفات! 😆
- 🔥 **تكامل CurseForge و Modrinth**. تصفح وتنزيل المودات وحزم الموارد مباشرة من المشغل.
- 📦 **استيراد وتصدير حزم المودات**. توافق كامل مع معايير CurseForge و Modrinth!
- 🔒 **دعم أنظمة حسابات متعددة**. تسجيل دخول Microsoft الرسمي و Mojang Yggdrasil API و [ely.by](https://ely.by/) وخوادم مخصصة!
- 🔗 **لعب جماعي P2P**. العب مع أصدقائك عبر شبكة LAN افتراضية عبر الإنترنت دون إعدادات شبكة معقدة!
- 🔑 **توقيع رقمي وحزم حديثة**. دعم `appx` و `appinstaller` على Windows دون تحذيرات SmartScreen! 😎
