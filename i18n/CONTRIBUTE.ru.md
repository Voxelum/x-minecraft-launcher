## Начало работы

В этом разделе описывается, как настроить окружение, изменить код и отправить PR.

### Нужные зависимости

- Node.js >=18.17.0
- pnpm (можно установить с помощью [corepack](https://nodejs.org/api/corepack.html) от Node.js)

### Настройка окружения

Используйте git для клонирования проекта:

```sh
git clone https://github.com/Voxelum/minecraft-launcher-core-node
```

Если у вас нет `pnpm`, вы можете использовать corepack для его установки:

```sh
corepack enable
```

Теперь у вас должен быть установлен `pnpm`. Выполните команду установки для загрузки зависимостей:

```sh
pnpm install
```

### Как разрабатывать

Код разделен на отдельные проекты, которые находятся в папке `packages`. Большинство из них реально простые (содержат только один файл `index.ts` или несколько файлов).

Для разработчиков библиотек мы рекомендуем использовать стиль TDD (Test Driven Development). Вы можете сначала добавить тесты, а затем написать код для их прохождения.

Мы используем [vitest](https://vitest.dev/) в качестве тестового фреймворка. Вы можете запустить его с помощью `pnpm run test` или `pnpm vitest` для запуска тестов в режиме наблюдения.

Пожалуйста, [ознакомьтесь с документацией vitest](https://vitest.dev/guide) для более подробной информации.

### Как собирать

Вы можете собрать проект локально, чтобы убедиться, что он проходит проверку PR. Сборка разделена на 3 части:

1. Сборка esm mjs файлов
2. Сборка cjs js файлов
3. Сборка typescript dts файлов

Вам нужно использовать рекурсивную опцию pnpm для выполнения команд сборки:

```sh
pnpm build:cjs --parallel # сборка cjs
pnpm build:esm --parallel # сборка mjs
pnpm build:type --parallel # сборка dts
```

### Закоммить свой код

Убедитесь, что вы коммитите свой код, используя [формат conventional commit](https://www.conventionalcommits.org/en/v1.0.0-beta.2/). GitHub Action будет использовать ваше сообщение коммита для генерации changelog и обновления версии. Это важно.

### Перед отправкой PR

Убедитесь, что вы выполнили `pnpm lint`, чтобы пройти линтинг, иначе проверка PR не будет пройдена.
