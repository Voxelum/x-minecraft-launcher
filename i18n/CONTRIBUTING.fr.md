### Stack Technologique & Architecture

Vue d'ensemble des outils et technologies utilisés :

- [Node.js >=18.17.0](https://nodejs.org/) : Environnement des bibliothèques de base.
- [Electron 27](https://electron.atom.io) : Environnement d'exécution de l'application.
- [pnpm](https://pnpm.io/) : Gestionnaire de paquets du monorepo.
- [TypeScript](https://www.typescriptlang.org/) : Langage principal du projet.
- [Vue & Vite](https://vuejs.org/) : Interface utilisateur et système de build.

### Guide de Contribution

1. **Cloner le projet avec ses sous-modules** :
   ```bash
   git clone --recurse-submodules https://github.com/Voxelum/x-minecraft-launcher
   ```
2. **Installer les dépendances** :
   ```bash
   pnpm install
   ```
3. **Lancer le serveur de développement** :
   ```bash
   pnpm dev
   ```
4. **Vérifier les types et le style de code** :
   ```bash
   pnpm check
   pnpm lint
   ```
