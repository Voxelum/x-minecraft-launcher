如果您已安装 winget，可以使用以下命令安装：

```bash
winget install CI010.XMinecraftLauncher
```

通过 Homebrew (macOS tap) 安装：

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

在 Linux 上，XMCL 也可以通过 Flathub 获取：

```bash
flatpak install flathub app.xmcl.voxelum
```

## 功能特性

- 📥 **自动补全与下载**。支持从官方或第三方镜像源下载 `Minecraft`、`Forge`、`Fabric`、`Quilt`、`OptiFine`、`JVM`。
- ⚡️ **极速下载**。通过 HTTP/HTTPS 代理复用连接，多线程分片并发下载。
- 💻 **跨平台**。基于 Electron 构建，支持 🗔 Windows 10/11、🍎 macOS 和 🐧 Linux。
- 📚 **多实例管理**。创建相互隔离的游戏实例，独立管理不同版本、模组和启动参数。
- 🗂 **智能资源管理**。利用硬链接和符号链接安装模组资源，避免文件重复占用磁盘空间！ 😆
- 🔥 **原生集成 CurseForge & Modrinth**。直接在启动器内搜索并一键安装模组与资源包。
- 📦 **模组包导入/导出**。完全兼容 CurseForge 与 Modrinth 官方规范整合包！
- 🔒 **多账户系统**。内置微软官方登录、Mojang Yggdrasil API，支持 [ely.by](https://ely.by/)、[littleskin.cn](https://littleskin.cn) 及自定义认证服务器！
- 🔗 **P2P 局域网联机**。即使不在同一物理网络下，也能通过虚拟局域网与好友联机游玩！
- 🔑 **代码签名与现代打包**。Windows 下支持 `appx` 和 `appinstaller` 安装，告别 SmartScreen 拦截！ 😎
