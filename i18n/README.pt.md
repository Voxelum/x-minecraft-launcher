Visite o [site oficial](https://xmcl.app) para baixar o aplicativo!

Se você possui o winget instalado, pode usá-lo para instalar:

```bash
winget install CI010.XMinecraftLauncher
```

Instalação via Homebrew (macOS tap):

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

No Linux, o XMCL também está disponível no Flathub:

```bash
flatpak install flathub app.xmcl.voxelum
```

## Recursos

- 📥 **Download e autocompletar**. Suporte para baixar `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` dos espelhos oficiais ou de terceiros.
- ⚡️ **Download rápido**. Reutiliza conexões via agentes HTTP/HTTPS e baixa partes de arquivos simultaneamente.
- 💻 **Multiplataforma**. Desenvolvido em Electron com suporte a 🗔 Windows 10/11, 🍎 macOS e 🐧 Linux.
- 📚 **Multi-instâncias**. Crie instâncias isoladas para separar versões, mods e configurações de inicialização.
- 🗂 **Gerenciamento eficiente de recursos**. Links físicos e simbólicos para gerenciar arquivos sem duplicá-los, economizando espaço em disco! 😆
- 🔥 **Integração nativa com CurseForge e Modrinth**. Baixe mods e pacotes de recursos diretamente pelo inicializador.
- 📦 **Importação/Exportação de modpacks**. Total compatibilidade com formatos de modpacks do CurseForge e Modrinth!
- 🔒 **Suporte a múltiplas contas**. Login oficial da Microsoft, Mojang Yggdrasil API, [ely.by](https://ely.by/) e servidores personalizados de autenticação!
- 🔗 **Conexão multijogador P2P**. Jogue em rede local virtual pela internet com amigos sem complicação!
- 🔑 **Assinatura de código & empacotamento moderno**. Suporte a pacotes `appx` e `appinstaller` no Windows sem alertas do SmartScreen! 😎
