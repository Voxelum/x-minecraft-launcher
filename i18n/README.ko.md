[공식 웹사이트](https://xmcl.app)를 방문하여 런처를 다운로드하세요!

winget이 설치되어 있다면 다음 명령어로 설치할 수 있습니다:

```bash
winget install CI010.XMinecraftLauncher
```

Homebrew (macOS tap)를 통한 설치:

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

Linux 환경에서는 Flathub을 통해서도 설치할 수 있습니다:

```bash
flatpak install flathub app.xmcl.voxelum
```

## 주요 기능

- 📥 **자동 다운로드 및 무결성 검사**. 공식 및 서드파티 미러에서 `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` 다운로드 지원.
- ⚡️ **초고속 다운로드**. HTTP/HTTPS 에이전트를 통한 연결 재사용 및 멀티스레드 분할 동시 다운로드.
- 💻 **크로스 플랫폼**. Electron 기반으로 🗔 Windows 10/11, 🍎 macOS, 🐧 Linux 완벽 지원.
- 📚 **다중 인스턴스 격리 관리**. 게임 버전, 모드, 실행 설정을 독립된 프로필로 격리하여 관리.
- 🗂 **스마트 리소스 관리**. 하드 링크 및 심볼릭 링크를 활용하여 모드 파일 중복을 방지하고 디스크 용량 절약! 😆
- 🔥 **CurseForge & Modrinth 통합**. 런처 내부에서 모드 및 리소스팩을 직접 검색하고 원클릭 다운로드.
- 📦 **모드팩 가져오기/내보내기**. CurseForge 및 Modrinth 표준 모드팩 규격 완벽 호환!
- 🔒 **다중 계정 시스템 지원**. Microsoft 공식 로그인, Mojang Yggdrasil API, [ely.by](https://ely.by/), [littleskin.cn](https://littleskin.cn) 및 커스텀 인증 서버 지원.
- 🔗 **P2P 멀티플레이어**. 복잡한 포트포워딩 없이 가상 LAN을 통해 인터넷으로 친구들과 즉시 멀티플레이 가능!
- 🔑 **코드 서명 및 최신 패키징**. Windows에서 `appx` 및 `appinstaller`를 지원하여 SmartScreen 경고 없이 안전하게 설치! 😎
