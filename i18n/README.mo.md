Vizitați [site-ul oficial](https://xmcl.app) pentru a descărca aplicația!

Dacă aveți winget instalat, îl puteți folosi pentru instalare:

```bash
winget install CI010.XMinecraftLauncher
```

Instalare prin Homebrew (macOS tap):

```bash
brew tap voxelum/xmcl
brew install --cask voxelum/xmcl/xmcl
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```

Pe Linux, XMCL este de asemenea disponibil pe Flathub:

```bash
flatpak install flathub app.xmcl.voxelum
```

## Funcționalități

- 📥 **Descărcare și completare automată**. Descărcare `Minecraft`, `Forge`, `Fabric`, `Quilt`, `OptiFine`, `JVM` din surse oficiale sau alternative.
- ⚡️ **Descărcare rapidă**. Reutilizarea conexiunilor prin agenți HTTP/HTTPS și descărcare concurentă a fișierelor pe bucăți.
- 💻 **Multiplatformă**. Bazat pe Electron, compatibil cu 🗔 Windows 10/11, 🍎 macOS și 🐧 Linux.
- 📚 **Management multi-instanțe**. Creați profiluri izolate pentru a separa versiunile de joc, modurile și setările de lansare.
- 🗂 **Gestionare eficientă a resurselor**. Utilizează legături hard și simbolice pentru a instala modurile fără duplicare de fișiere și pentru a economisi spațiu pe disc! 😆
- 🔥 **Integrare CurseForge & Modrinth**. Căutați și descărcați resurse direct din launcher.
- 📦 **Import și export modpack-uri**. Compatibilitate completă cu formatele standard CurseForge și Modrinth!
- 🔒 **Suport pentru conturi multiple**. Autentificare Microsoft, Mojang Yggdrasil API, [ely.by](https://ely.by/) și servere personalizate de autentificare!
- 🔗 **Multiplayer P2P**. Jucați cu prietenii prin rețea locală virtuală pe internet fără configurații de rețea complicate!
- 🔑 **Semnătură de cod și pachete moderne**. Pe Windows acceptă pachete `appx` și `appinstaller` fără avertismente SmartScreen! 😎
